# Shared: copyright and the oracle

- The **oracle** is a modern, in-copyright translation (e.g. a Fathers of the Church volume)
  that the user supplied. It lives only under `_source/oracle/`. If the work folder is in a git
  repo, `_source/` must be git-ignored.
- A **copyright base** (`base_license: copyright`) is treated like the oracle: the verified
  base text lives in `_source/<LANG>` (the `lang_dir`), never in a committed folder. Only the
  English is published.
- **Consult, never copy.** Nothing from the oracle may enter the source text, the English, the
  config, or any report beyond **a few words** needed to name a specific discrepancy.
- **The oracle is a detector, never an authority.** In source-text passes, a discrepancy is
  settled on the **page image**. In translation passes, it is settled on **our source text**.
  An oracle can follow a different edition or apparatus reading, can paraphrase, abridge or
  expand, and can simply be wrong. Record which of these it is.
